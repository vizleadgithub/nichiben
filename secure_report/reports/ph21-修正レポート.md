# Ph.21 修正レポート — 受講者サイト パンくずリスト 格納型 XSS 修正

**作成日:** 2026-06-30  
**対応区分:** STU-XSS-14（新規発見）  
**優先度:** 高  
**発見経緯:** XSS-02 テスト（商品名へのスクリプト注入）の検証中に、受講者サイト商品詳細ページのパンくずリストでも同スクリプトが実行されることを確認

---

## サマリー

| 項目 | 値 |
|------|-----|
| 脆弱性種別 | 格納型 XSS（Stored XSS） |
| 影響サイト | 受講者サイト（alfproduct/public） |
| 影響ページ | `/product/detail.php`・`/product/detail_review.php` |
| 修正ファイル | `alfproduct/module/functions.php`・`alfproduct/module/functions_mst.php` |
| 修正箇所 | `get_product_pankuzu()` 関数内 商品名・カテゴリ名の HTML 出力 |

---

## 問題の詳細

### 再現手順

1. CMS 商品管理で商品名に XSS ペイロードを登録する（例: `"><img src=x onerror=alert('XSS')>`）
2. 受講者サイトの商品詳細ページ（`/product/detail.php?pid={id}`）にアクセスする
3. パンくずリスト最終ノードでスクリプトが実行される

### 出力された HTML（修正前）

```html
<div class="pankuzu" style="color:#4b3921;font-size:14px;"><ul>
  <li><a href="https://nichibenren-stg2.alfcloud.com">TOP</a></li>
  <li>…</li>
  <li><a href="…/product/list.php?pcid=523">その他動画</a></li>
  <li>…</li>
  <li>"><img src=x onerror=alert('XSS-02')></li>  ← 未エスケープ
</ul></div>
```

### 根本原因

`get_product_pankuzu()` 関数（`module/functions.php` および `module/functions_mst.php`）において、カテゴリ名（`$arr_pan_cat[$i]['name']`）は `htmlspecialchars()` が適用されていたが、パンくずリストの最終ノードに出力される**商品名（`$product_name`）は未適用**だった。

`$product_name` は DB の `tbl_product.product_name` から直接取得しており、CMS 管理者が任意の値を登録できるため、格納型 XSS として成立する。

## 修正内容

### `alfproduct/module/functions.php`

#### 修正箇所 1（商品詳細分岐 L.652）

```diff
  if (!empty($product_name)) {
      $pankuzu .= '<li>&nbsp;<img src="/img/c_ar_2.png" alt="＞" style="height:10px;" />&nbsp;</li>';
-     $pankuzu .= '<li>'.$product_name.'</li>';
+     $pankuzu .= '<li>'.htmlspecialchars($product_name, ENT_QUOTES, 'UTF-8').'</li>';
  }
```

  if (!empty($product_name)) {

---

## 補足：`$pankuzu` を Smarty テンプレートで raw 出力している理由

`$pankuzu` は PHP 側で HTML を組み立てた文字列を Smarty 変数に渡しているため、テンプレート側では `{$pankuzu}` と raw 出力している（Smarty の `|escape` を適用すると HTML タグごとエスケープされてしまう）。

今回の修正により、HTML を組み立てる PHP 側で値を確実にエスケープするよう対処した。

## テスト手順

1. CMS 商品管理にて商品名を `"><img src=x onerror=alert('XSS-14')>` に変更して保存する
2. 受講者サイト `/product/detail.php?pid={id}` にアクセスする
3. パンくずリスト末尾に `&quot;&gt;&lt;img src=x onerror=alert(...)&gt;` と HTML エスケープされて表示されることを確認する（アラートは発生しない）
4. `/product/detail_review.php?pid={id}` でも同様に確認する
