# Ph.22 修正レポート — 格納型 XSS（主催者名・商品説明）

**対象脆弱性分類**: STU-XSS-15（disp_sponsor）/ STU-XSS-16（memo|nl2br）  
**修正日**: 2026-06-30  
**修正ファイル数**: 14 ファイル（PHP 12 + Smarty テンプレート 2）

---

## 背景

Ph.21（パンくずリスト格納型 XSS）の調査をきっかけに、ログイン後の新着eラーニング一覧画面のカード内でも同種の格納型 XSS が再現できることが確認された。

---

## 脆弱性 1：主催者名（disp_sponsor）格納型 XSS

### 概要

会場研修商品の「主催」フィールド表示時、CMS マスタデータ（`mtb_bar_association.name`）をエスケープせず HTML 文字列結合していた。テンプレートでそのまま raw 出力されるため、CMS 側の弁護士会マスタ名称にスクリプトを仕込むことで受講者サイト全体で XSS が実行できる状態だった。

### 攻撃経路

```
CMS 弁護士会マスタ（name フィールド）
 → "><img src=x onerror=alert(1)> を入力
 → 商品の主催者として設定
 → 受講者サイト 商品一覧/詳細 ページでスクリプト実行
```

### 根本原因

`disp_sponsor` を PHP 側で構築する際、`<br />` タグと結合する前に `$mtb_bar_association[$sponsor]` をエスケープしていなかった。テンプレートは意図的な `<br />` を含む文字列をそのまま出力するため、Smarty 側での `|escape` 適用も不可能な設計だった。

```php
// 修正前（脆弱）
$disp_sponsor.= $mtb_bar_association[$sponsor].'<br />';

// 修正後（安全）
$disp_sponsor.= htmlspecialchars($mtb_bar_association[$sponsor], ENT_QUOTES, 'UTF-8').'<br />';
```

## 脆弱性 2：商品説明（memo）Smarty nl2br XSS

### 概要

商品詳細ページの「商品説明」「備考」フィールドを Smarty テンプレートで出力する際、`|nl2br` のみ適用し `|escape` が漏れていた。CMS 管理者が商品説明フィールドにスクリプトを入力すると受講者側で実行される状態だった。

### 修正内容

```smarty
<!-- 修正前（脆弱）-->
<!--{$product_list.memo|nl2br}-->

<!-- 修正後（安全）-->
<!--{$product_list.memo|escape|nl2br}-->
```

`|escape` を先に適用し HTML 特殊文字をエスケープしてから `|nl2br` で改行変換する正しい順序に修正。

## テスト手順

### XSS-15（disp_sponsor）

1. CMS「弁護士会マスタ」管理画面から、いずれかの弁護士会名を `"><img src=x onerror=alert('XSS-15')>` に変更する
2. その弁護士会が主催する会場研修商品を用意し、受講者サイト `/product/list_new_training.php` にアクセスする
3. 商品カードの「主催」欄でスクリプトが実行されないことを確認する
4. `/product/detail.php`、`/product/list.php`、`/search/index.php` 等でも同様に確認する

### XSS-16（memo|nl2br）

1. CMS 商品管理から、いずれかの商品の「商品説明」フィールドを `"><img src=x onerror=alert('XSS-16')>` に変更する
2. 受講者サイト `/product/detail.php?pid={id}` にアクセスする
3. 商品説明欄でスクリプトが実行されないことを確認する
4. スマートフォン版テンプレートでも同様に確認する
