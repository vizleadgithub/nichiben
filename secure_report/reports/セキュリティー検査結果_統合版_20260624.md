#### [CMS-H-01〜06] 反射型クロスサイトスクリプティング × 6件

| 項目 | 内容 |
|------|------|
| 重大度 | **高** (CVSS 7.1) |
| スキャンURL | `https://cms.nichibenren-stg2.alfcloud.com/alfproduct/product/index.php` |
| 脆弱パラメータ | `search_start_date`, `search_product_code`, `search_end_date`, `search_product_name`, `search_teacher`, `search_word` |

**ソースコード上の原因（確認済み）:**  
`alflearning/alflearning-cms/alfproduct/product/index.php` **行356**

```php
echo "<!--[".$sql.$where.$order.$offset."]-->";
```

`$where` にユーザー入力が HTMLエスケープなしで含まれるため、`]-->` を含むペイロードで HTML コメントを脱出して任意の JavaScript が実行される。

**実証済みペイロード（PDFより）:**
```
search_start_date=--> <script>alert(249)</script>
```

**修正対象ファイル:**

| ファイル | 行 | 修正方針 |
|---------|---:|---------|
| `alflearning/alflearning-cms/alfproduct/product/index.php` | 138〜146, 356 | デバッグ echo 行（356）を削除。セッション格納前のエスケープも合わせて対応 |

#### 最高リスク箇所の例

```php
// cms_exam2/answer_set_list_review.php:80 — JS onclick 内への student_id 出力

<?= $student['student_name'] ?>
```

#### 修正方針

```php
// HTML コンテキスト
<?= htmlspecialchars($student['student_name'], ENT_QUOTES, 'UTF-8') ?>

// JavaScript コンテキスト（onclick 属性内）
onclick="func(<?= json_encode($student_id) ?>)"

// nl2br は HTML エスケープなしのため必ず置換
```
