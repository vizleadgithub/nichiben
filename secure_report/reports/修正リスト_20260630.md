# セキュリティ修正リスト（画面・入力項目別）

- 作成日: 2026-06-22
- 更新日: 2026-06-30（Ph.1〜Ph.21 全対応完了版）
- 方針確定事項:
  - ① CMS-H-01〜16 本体ファイル
  - ④ エドテク計上の exam2 backup 9 件 → 控除（dead file）
  - ⑤ `Cross-Origin-Embedder-Policy: require-corp`（COEP）は外部動画配信サーバーとの互換性のため削除。COOP + CORP は維持（Ph.7 更新）
  - ⑥ alflearning-api の `csrf_protection` は `FALSE` のまま維持。REST API には CSRF 保護不要のため意図的（Ph.11 更新）
